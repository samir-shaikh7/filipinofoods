# 🇵🇭 Filipino Food Kuwait — Premium Restaurant Ordering Platform

A modern premium Filipino restaurant ordering platform built with React, Vite, TypeScript, Tailwind CSS, Supabase, and a fully dynamic admin panel.

Designed for:
- Fast online food ordering
- Mobile-first premium UI/UX
- WhatsApp-based checkout flow
- Dynamic menu management
- Multi-restaurant scalability
- High performance and SEO optimization
