# 🇵🇭 Filipino Food Kuwait — Premium Restaurant Ordering Platform

A modern restaurant ordering platform built for a Filipino restaurant in Kuwait.

The platform provides a premium mobile-first experience with a dynamic menu, WhatsApp ordering, and a secure admin panel for managing restaurant content in real time.

🌐 **Live Website:** https://www.filipinofood.online

---
